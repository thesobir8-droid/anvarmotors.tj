# ANVAR MOTORS

Сайти қисмҳои эҳтиётии мошин бо админ панел.

## Чӣ гуна кушодан

1. Файли `index.html`-ро бо браузер кушоед (ду бор клик).
2. Барои админ: `admin.html`-ро кушоед.

> Агар аксҳо ва маълумот нигоҳ дошта нашаванд, сайт-ро тавассути сервери маҳаллӣ кушоед (масалан Live Server дар VS Code/Cursor).

## Админ панел

- Суроға: `admin.html`
- Рамзи пешфарз: `anvar2026`

Дар админ панел метавонед:

- маҳсулот илова/таҳрир/нест кунед
- акс аз компютер ё URL гузоред
- матнҳои саҳифаро иваз кунед
- логотип ва оморҳоро (масалан «7 сол таҷриба») иваз кунед
- рақамҳои телефон, Instagram, Telegram ва WhatsApp-ро танзим кунед
- рамзи админро иваз кунед (забони «Иваз кардани рамз»)

## Файлҳо

- `index.html` — саҳифаи асосӣ
- `admin.html` — админ панел
- `anvar-motors-logo.png` — логотип
- `css/styles.css` — дизайн
- `js/` — мантиқи сайт ва админ
